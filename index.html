묶음매칭은 카드 금액의 합계가 원인행위 금액과 1원 단위까지 정확히 일치하고, 설정한 최대 묶음 건수·날짜 범위 안에서 가능한 조합이 하나일 때만 자동 확정합니다.

5단계에서 추가된 기능

2~N건 합계 탐색

남은 카드내역 가운데 2건 이상을 조합하여 하나의 원인행위 금액과 정확히 같은 합계를 찾습니다.

날짜 범위 제한

원인행위일을 기준으로 설정한 날짜 범위 안의 카드내역을 우선 사용하여 엉뚱한 조합을 줄입니다.

유일한 조합만 자동확정

정확히 맞는 조합이 하나일 때만 묶음 자동매칭합니다. 두 조합 이상이면 직접 확인으로 남깁니다.

카드 중복사용 방지

한 번 자동매칭된 카드내역은 다른 원인행위 묶음에 다시 사용하지 않습니다.

사용설명서

① 원인행위목록과 카드사용내역을 넣습니다.
② 전체 자동매칭 실행을 누릅니다.
③ 금액 1:1 → 날짜·내용 2차 → 여러 카드 묶음 순서로 자동 분석합니다.
④ 묶음 조합이 하나면 자동매칭하고, 여러 조합이면 직접 확인으로 표시합니다.

4단계에서 추가된 기능

날짜 가까움 반영

같은 금액 후보 가운데 원인행위일과 카드 승인일의 차이가 작을수록 높은 점수를 줍니다.

가맹점·채주·적요 비교

두 자료의 설명에서 공통 단어와 문자열 유사도를 계산하여 후보 순위를 높입니다.

1순위 우세 여부 확인

최고점 후보가 기준점수 이상이고 2순위보다 충분히 우세할 때만 2차 자동매칭합니다.

직접 확인 유지

근거가 부족하거나 후보 점수가 비슷하면 자동 확정하지 않고 직접 확인 대상으로 남깁니다.

4단계 설정

금액은 반드시 동일해야 하며, 기준 미달 건은 자동 확정하지 않습니다.

사용설명서

① 원인행위목록과 카드사용내역을 넣습니다.
② 파일이 분석되면 정밀 자동매칭을 누릅니다.
③ 1차 자동매칭은 금액이 양쪽에 각각 1건인 자료입니다.
④ 중복 금액은 날짜와 내용 유사도를 이용해 2차 판정합니다.
⑤ 확실하지 않은 건은 직접 확인 탭에서 확인합니다.

2단계에서 추가된 기능

엑셀 자동 읽기

첫 번째 시트만 고정하지 않고 각 시트를 살펴보며, 상단 약 30행 안에서 실제 제목행을 탐색합니다.

파일 종류 자동 판별

원인행위·지급방법·채주·품의 등의 항목과 승인일자·승인금액·카드번호·가맹점 등의 항목을 비교해 파일 종류를 판단합니다.

건수 자동 계산

제목행 아래의 실제 데이터 행 중 빈 행과 합계 행을 제외하여 대략적인 자료 건수를 계산합니다.

금액 열 자동 탐색

원인행위금액·지출금액·승인금액·이용금액 등 대표 금액 제목을 찾아 합계를 계산합니다.

현재는 2단계입니다. 파일 읽기와 기초 분석까지 실제 작동합니다. 0원 맞추기 버튼은 다음 3단계에서 1:1 금액 자동매칭 기능을 연결할 예정입니다.
Program by Kwon O Young. 오춘기 권오영

설정

현재 2단계에서는 파일 분석 기준을 자동으로 적용합니다. 3단계 이후에는 날짜 허용범위, 최대 묶음 건수 등 매칭 설정을 추가할 예정입니다.

사용설명서

① 원인행위목록과 카드사용내역 엑셀을 각각 넣습니다.
② 프로그램이 시트·제목행·파일 종류·금액 열을 자동으로 찾습니다.
③ 분석이 끝나면 각 파일 아래에 건수와 합계금액이 표시됩니다.
④ 두 파일이 정상 인식되면 0원 맞추기 버튼이 활성화됩니다. 현재 2단계에서는 버튼 활성화까지만 하며 실제 매칭은 3단계에서 구현합니다.

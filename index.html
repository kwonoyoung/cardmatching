STEP 8에서 추가된 기능

합계행 · 보존 검증

엑셀 합계행과 읽은 금액이 같은지, 매칭·확인 필요·한쪽만·제외의 합계가 전체 금액과 같은지 스스로 확인해 빠지거나 겹친 건을 잡아냅니다.

승인 · 취소 자동 정리

같은 승인번호의 승인·취소는 전액취소면 서로 지우고, 부분취소면 남은 금액으로 맞춥니다. 원 결제가 없는 취소는 ‘이전 청구분 취소’로 남깁니다.

지출일 조회기간 도우미

1~15일 사용분은 그달 27일, 16일~말일 사용분은 다음 달 12일 지출입니다. 카드 파일의 지출일을 알려 주고 두 지출분이 섞이면 경고합니다.

제외 · 되돌리기 · 차액 연결

이번 지출분이 아닌 건은 제외해 남은 금액에서 빼고, 배송비처럼 금액이 다른 건은 사유를 적어 연결합니다. 엑셀에 그대로 남습니다.

설정 · 조회기간 도우미

① 매칭 기준

카드를 먼저 쓰고 나중에 원인행위한 경우. 묶음 탐색·흐리게 표시에 씁니다.

원인행위를 먼저 하고 며칠 뒤 카드를 쓴 경우(사전 원인행위).

같은 금액이 여러 건일 때 날짜 점수를 주는 범위.

여러 결제를 한 원인행위로 묶어 볼 최대 건수.

날짜(45점)+내용 유사도(45점) 합이 이 점수 이상일 때 자동 확정.

후보 간 점수차가 이보다 작으면 ‘확인 필요’로 보냅니다.

결의확정액 = 원인행위금액이고 결의가능금액이 0원인 건을 자동으로 제외합니다. 앞 기간 건이 섞였을 때 켜세요.

③ 예시자료

사용설명서

순서

  1. K-에듀파인 원인행위(지급방법-카드) 목록과 카드사 승인내역(전체승인)을 엑셀로 내려받습니다. 조회기간은 [설정 · 조회기간]의 도우미를 보세요.
  2. 두 파일을 화면에 한꺼번에 끌어다 놓습니다. 내려받은 그대로 넣어야 합계행 검증이 맞습니다.
  3. 합계 검증과 취소 정리, 1차·2차·묶음 자동매칭이 저절로 진행됩니다.
  4. 확인 필요에서 추천안을 확인해 확정합니다(대부분 [추천안 모두 확정] 한 번).
  5. 짝 맞추기에서 남은 건을 직접 연결하거나, 이번 지출분이 아닌 건을 [제외]합니다.
  6. 계기판의 카드결제 남은 금액이 0원이 되면 [결과 엑셀저장]으로 남기고, ‘매칭 완료’ 시트를 보며 지출결의합니다.

결과 구분

  • 1차 자동 — 금액이 1:1로 하나뿐인 건 · 2차 자동 — 같은 금액 여러 건 중 날짜·내용 점수로 확정 · 묶음 자동 — 카드 여러 건 합계가 원인행위와 일치(조합이 하나뿐일 때)
  • 확인 후 — 확인 필요에서 담당자가 확정 · 직접 연결 — 짝 맞추기에서 연결(차액 사유 기록 가능)
  • 제외 — 이번 지출분이 아니라 뺀 건. 남은 금액에 들어가지 않으며 [되돌리기]로 다시 넣습니다.

자주 묻는 것

  • ‘합계행과 읽은 금액이 다름’ — 엑셀에서 행을 지우거나 고친 경우입니다. 원본을 다시 내려받아 넣으세요.
  • 한쪽만 있는 건이 너무 많음 — 대부분 조회기간 문제입니다. 카드 칸에 표시된 지출분이 하나인지 확인하고, 앞 기간 원인행위가 섞였다면 ‘지출결의 끝난 원인행위 빼기’를 켜세요.
  • 마이너스 금액 카드내역 — 앞 기간 결제의 취소(이전 청구분 취소)입니다. 관련 원인행위의 감액·반납을 확인하세요.
  • 정리 내용 저장 — 화면에서 정리한 내용은 새로고침하면 사라집니다. 꼭 [결과 엑셀저장]으로 남기세요.
